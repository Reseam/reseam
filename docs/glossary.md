# Glossary

- **Bundle** — signed archive containing compiled patch JARs, DEX extensions, and `manifest.toml`. File extension `.reseam`.
- **Patch** — a single unit of modification to a target app. Kotlin, declared as a top-level `val` using the patch DSL.
- **Extension** — Java or Kotlin code compiled to DEX and injected into the target app by a patch.
- **Shared module** — an extension reused across apps. Lives under `shared/`.
- **Engine** — `reseam-patcher`. Loads bundles, orders patches, runs them against a mutable APK.
- **`PatchRuntime`** — the context passed to each patch in `execute`. Exposes bytecode, manifest, resources, files, options, and logging.
- **Fingerprint** — describes a method by stable properties (strings, return type, parameters). Resolved at patch time to work around obfuscation.
- **DEX** — Dalvik Executable. Android's bytecode format.
- **AXML** — Binary Android XML. The manifest format inside an APK.
- **`manifest.toml`** — bundle-level metadata (name, author, description, format_version).
- **`patches.json`** — release index listing versions, download URLs, and the bundle's public signing key.
- **Signing seed** — Ed25519 private key for signing bundles. Generated by `reseam bundle keygen`.
- **Reseam Manager** — the Android client app.
- **CLI** — `reseam`. Packs bundles, signs them, applies them, generates release indexes.
